# 复盘数据包操作说明

## 使用方式

推荐直接在 Codex 中说：

```text
生成复盘数据包：暑促，2026/7/1–7/15，目标 1.2 亿。
```

也可以运行稳定命令：

```bash
PYTHONPATH=src python scripts/review_data_pack.py \
  --name 暑促 --start 2026-07-01 --end 2026-07-15 --target 1.2亿
```

必填项是活动名称、开始日期、截止日期和活动目标。已配置的活动会自动补齐定金、蓄水来源期；也可用以下参数明确指定：

- `--deposit-source-start`、`--deposit-source-end`
- `--reservoir-source-start`、`--reservoir-source-end`

先验证、不创建飞书表格时加 `--dry-run`；使用内置样例验证流程时同时加 `--sample --dry-run`。

## 结果与状态

命令只输出一个 JSON 结果，包含本期、去年同期、各模块状态、检查汇总、失败模块和本地快照路径。正常写入成功时还会返回新的飞书表格链接。

退出码：

- `0`：流程完成
- `2`：输入或本地配置不正确
- `3`：全部取数模块失败
- `4`：飞书创建或回读失败

单个模块失败时，其状态会明确显示为 `failed` 或 `not_applicable`，不会把缺失数据伪装成 0。

## 本地快照与重跑

每次运行都会在 `outputs/review_pack/<运行时间>_<活动名>/review_pack.json` 保存独立快照。飞书写入失败时，先查看结果中的失败模块和配置提示；修复数据源或认证后，使用相同参数重新运行即可。重跑会创建新的快照和新的飞书表格，不会覆盖旧结果或已有文档。

若活动没有预设策略来源期，请先补充四个来源期参数。若数据库模块失败，应先解决该模块问题并重新执行 `--dry-run`；只有核心模块全部成功后再创建飞书表格。
