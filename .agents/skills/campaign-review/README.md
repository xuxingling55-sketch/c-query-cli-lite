# 活动复盘 Skill 使用说明

给同事的一键使用指南。本目录下的 `SKILL.md` 是 AI 执行用的指令，本文件是给人看的。

## 怎么用

1. 克隆本仓库，用支持 Agent Skills 的工具（Cursor 等）打开仓库根目录，技能会被自动发现，无需安装。
2. 对 AI 说一句话即可触发，例如：
   - "复盘暑促活动，活动期 7 月 1 日到 7 月 20 日，目标 5000 万"
   - "帮我复盘 XX 活动"
3. AI 会按固定流程执行：取数 → 目标达成评估 → 缺口归因 → 定性证据 → 结论建议 → 产出报告到 `reports/YYYYMMDD_<活动名>_复盘.md`。

缺少的输入（活动名、起止日期、目标、报告读者）AI 会主动追问，直接回答即可。

## 前置条件

- **正式取数**：需要按仓库根目录 `config.example.json` 配置好数据库连接；结果要写飞书表格时需安装 `lark-cli` 并完成认证。
- **只想看流程**：对 AI 说"预演"或"测试"，会用示例数据走通流程，不查真实数据、不建飞书表格。
- **录音定性分析（可选）**：依赖 comms-dataprep、speaker-attribution-prep 两个个人技能；没有安装则该步骤自动跳过，不影响其余流程。

## 配套技能

- `review-data-pack`（本仓库自带）：一次取齐 8 个模块的复盘数据包。
- `report-polish`（本仓库自带）：复盘报告的结构与可读性规范。
