# 销售精力监控台 Demo

直接打开 `index.html` 即可使用，无需安装软件或启动服务。

## 数据说明

- 页面中的团队、销售、用户和经营指标均为模拟数据，仅用于演示交互与监控方式。
- 页面顶部持续显示“演示数据”，不能将当前结果用于真实业务判断。
- 模拟范围为 14 天、4 个团队、24 名销售和 600 名用户。

## 页面能力

- 按日期、观察窗口、团队、销售、学段和用户分层筛选。
- 查看 6 个核心指标、学段与用户分层热力图、趋势、异常提醒和销售排行。
- 从团队下钻到销售和用户明细，并支持搜索、重置和冲突条件提示。

## 接入真实数据

后续接入真实数据时，只需替换 `data.js` 的数据生成部分，并保持当前输出结构和字段名称不变。`metrics.js` 与 `app.js` 的数据接口无需调整。
