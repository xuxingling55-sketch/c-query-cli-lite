# C 端私域关键指标口径

## 用途

看板用于观察 C 端私域经营进度，覆盖营收、APP 新增流量、定金尾款、蓄水转化、家庭包、从小学和高净值续费。它不是订单明细查询工具。

## 时间与粒度

- 业务日期：页面明确展示“数据截止日期”，当前活动观察窗口为 2026 年 7 月。
- 数据粒度：趋势快照按自然日一行；顶部和表格指标为截至业务日期的累计值或当日值。
- 缺失日期：补齐日期并按 0 展示，不跨日期推断当日新增量。
- 分母为 0：比率统一返回 0，页面不得显示无穷大或异常字符。

## 来源表

- `dws.topic_order_detail`：订单、实付金额、商品和业务归因。
- `aws.crm_order_info`：电销营收补充。
- `aws.business_active_user_last_14_day`：高净值活跃用户池。
- APP 注册与激活相关汇总表：APP 新增流量。
- `xuxingling_202607_chongding_fine_summary`：冲顶营收目标与进度；不可用时回退到日推营收结果。

实际查询以同版本的 `sql/report.sql` 为准。来源表或字段定义变化时，必须先更新并重新验收 SQL，不能只修改页面说明。

## 主要指标

### 私域累计营收

商业化订单实付金额与符合公司口径的电销营收之和。页面拆分展示 APP 与电销，并与去年同期比较。

### APP 累计新增流量

活动窗口内 APP 端新增用户的累计值，只包含 Android、iOS 和 Harmony 指定来源。

### 定金尾款

- 定金用户：指定定金商品在固定定金窗口内的去重支付用户。
- 尾款用户：定金用户在定金支付后购买符合条件正价组合品的去重用户。
- 尾款率：尾款用户数 / 定金用户数。
- 尾款客单价：尾款营收 / 尾款用户数。

### 蓄水转化与转大

- 蓄水用户：在蓄水窗口内购买同步课加培优课流量品的去重用户。
- 转化：蓄水支付后再次购买任意符合口径商品。
- 转大：蓄水支付后购买正价组合品。
- 转化率或转大率：对应去重用户数 / 蓄水用户数。

### 家庭包与从小学

- 家庭包分子为“小初高品”订单，分母为组合品订单，同时展示小学、初中和高中团队占比。
- 从小学分子为“小学品加拓展”，分母为“小学品 + 小学品加拓展”。

### 高净值续费

高净值活跃池来自每日高净值用户标签；续费为同日购买指定商品的去重用户。续费率为续费用户 / 高净值活跃用户，客单价为续费营收 / 续费用户。

## 过滤与质量检查

- 仅统计正式业务数据，排除测试用户和无效订单。
- 人数和订单均按已确认主键去重。
- 最大业务日期必须等于本次指定日期或已声明的活动截止日期。
- 累计值不得小于上一日；金额、人数和订单数不得为负数。
- 页面汇总值必须与 `public/data/report.json` 一致。

## 敏感字段边界

快照只允许包含页面需要的汇总结果。禁止写入姓名、手机号、用户标识、订单明细、数据库地址、账号、密码、令牌和其他 Secret。发现敏感字段时必须停止发布并重新生成快照。
